# Gestor Académico SAM La Filarmónica
Aplicación web de gestión académica para la Escuela de Música SAM La Filarmónica de Callosa de Segura.  
Proyecto intermodular — 2º DAW.

---

## Introducción
Este proyecto nace con el objetivo de centralizar y digitalizar la gestión académica de una escuela de música: inscripciones, matrículas, pagos, publicaciones internas (anuncios) y consulta por parte del alumnado y profesorado.

Se divide en dos zonas:
- **Zona pública**: información general, prematrícula y eventos.
- **Zona privada**: paneles según rol (**admin**, **profesor**, **alumno**).
